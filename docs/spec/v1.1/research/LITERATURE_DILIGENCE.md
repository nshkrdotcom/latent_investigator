# Literature and Novelty Diligence

Novelty is unresolved and must not be inferred from the architecture feeling unusual.

## Timing

Begin this search **in parallel with Phase 0–2 implementation**, not after Gate 1. It is cheap compared with the build and determines whether a publication path exists.

The search does not block the tool prototype, but publication framing remains blocked until it is complete enough to characterize the nearest work honestly.

## Required intersections

Search at least:

1. competing-hypothesis / abductive investigation agents;
2. causal model populations and active causal discovery;
3. strategic multi-agent epistemics, theory of mind, deception, hidden-role games;
4. strategic communication and information design;
5. endogenous observation / observer-dependent evidence processes;
6. provenance, source authentication, misinformation lineage, and evidence dependence;
7. intelligence-analysis methods such as analysis of competing hypotheses;
8. long-horizon agent memory/state versus monolithic prompting;
9. evaluation of justified non-resolution / abstention / premature closure;
10. multi-agent worlds where the observation channel itself is strategically manipulated;
11. investigator/search systems that explicitly model heterogeneous actors' knowledge states;
12. systems where evidence provenance and strategic source identity are both latent.

## Search product

Maintain a compact table, not a new architecture docset:

- citation;
- task;
- hidden-state representation;
- whether hypotheses are generated or fixed;
- whether actors are strategic;
- whether actor knowledge is partial/heterogeneous;
- whether observation generation is endogenous;
- whether provenance/authentication is modeled;
- whether non-resolution is scored;
- whether evidence acquisition is active;
- nearest overlap with this project.

## Novelty criterion

The novelty question is about the **integrated computational object and measured failure mode**, not whether each ingredient has prior art.

Do not write a publication claim until the search is done against the actual implemented task and the Gate 1 behavior is known.
