# Claim Boundaries

## What a positive initial experiment could support

- explicit world/provenance state can improve specified investigation behaviors on controlled strategic-network environments;
- a particular evaluator can approximate frontier/oracle local judgments on specified judgment classes at measured cost/latency;
- candidate generation or local evaluation is a measurable bottleneck under the tested environment;
- evidence access changes investigation behavior in a measurable way;
- within the simulator, structured acquisition can select actions that better separate simulator-compatible candidate worlds.

## What it cannot support

- that the system works on secret institutional investigations;
- that it recovers true motives from real social-media feeds;
- that System One probabilities are globally calibrated causal likelihoods;
- that a synthetic strategic network represents human organizations generally;
- that the architecture is novel without dedicated literature diligence;
- that one provider/model result generalizes across model updates;
- that wider search is inherently better;
- that simulator `predict(world, action)` establishes general real-world evidence acquisition;
- that a negative small-scale Gate 1 result refutes a hypothesized advantage that only appears at longer persistent-state scales.

## Tool claim versus research claim

A tool can be useful even if component ideas are known. A publication requires a clear scientific contribution, which could be an evaluation environment/task, measured failure mode, architectural result, or cost/capability tradeoff. Novelty diligence is required before choosing that framing.
