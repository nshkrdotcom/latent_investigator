# Risk Register

| Risk | Consequence | Initial mitigation |
|---|---|---|
| Monolithic model already does the job | no research/tool reasoning advantage | run B0a/B0b immediately after simulator; scale reconnaissance before full core |
| Structured arm wins only because it uses more frontier compute | invalid architecture claim | compute-matched iterative monolithic B0b |
| Small cases are too easy | false kill / no scale test | explicit small/medium/large axis; small-only negative != long-scale falsification |
| Model stochasticity swamps seed effects | unstable conclusions | >=3 model replicates per seed in qualification; report seed vs replicate dispersion |
| Always-hedge policy scores well | fake non-identifiability success | mix resolvable/non-identifiable/transition cases; balanced resolution metrics |
| Candidate generator circles narrow explanation set | true world never evaluated | generation-oracle ablation; diversity/attack rounds |
| Cheap evaluator noise creates false-fit worlds | breadth hurts | frozen-workload Gate 2 before resource-breadth experiment |
| Sprawling worlds fit by adding assumptions | false explanatory advantage | redundancy-dominance tie-break and adversarial parsimony fixture |
| Raw model confidence treated as likelihood | false precision | ordinal aggregator; confidence logged separately |
| Correlated copied evidence counted repeatedly | narrative false certainty | provenance components contribute once |
| Per-world/per-evidence model calls explode | cost/latency dominates | mandatory cost projection; bounded batching with batch-vs-individual QC |
| Batching causes anchoring across worlds | distorted comparisons | freeze batching strategy and measure agreement against individual calls |
| Simulator acquisition API does investigator thinking | overclaimed active-inquiry result | scope acquisition claims to controlled simulator; label semantic predictions |
| Simulator templates leak mechanism | benchmark shortcut | surface perturbations, held-out templates, later independently authored worlds |
| Structured investigator receives more information than baseline | invalid comparison | identical evidence/action visibility tests |
| Reference architecture co-adapts to environment ontology | inflated result | generation oracle diagnostics; later external environments/independent cases |
| Jev context/state too large | unfair/failed local evaluator | bounded judgment slices; record truncation/refusal; never send whole investigation by default |
| Jev model alias drifts | irreproducible Gate 2 | record concrete returned model/version; pin where possible |
| Inference provider lacks strict schema support | malformed outputs | capability preflight, fail closed |
| Experiment becomes another spec project | no empirical signal | v1.1 is final pre-code patch; reproducible code failure required for further spec change |
| Synthetic success overclaimed as real-world validation | weak paper/tool claims | explicit claim boundaries and future external anchors |
