# Access Regimes

The project treats privileged access as an experimental variable.

For the same hidden world, define nested evidence regimes:

```text
public ⊂ limited ⊂ operator ⊂ oracle
```

## Public

Only surface observations and publicly attributable metadata.

## Limited

Adds selected provenance/authentication records available to a competent external investigator.

## Operator

Adds internal channel/provenance records, actor-access logs, and event metadata analogous to what an operator of the synthetic system could inspect.

## Oracle

Exposes enough simulator truth to resolve every fact that is in principle represented by the environment. The oracle regime is for diagnostic ceilings, not normal system evaluation.

## Access-curve questions

As access increases:

- does true-world retention improve?
- do false worlds disappear for valid reasons?
- does the number of surviving alternatives shrink only when new evidence discriminates them?
- does false certainty occur under public access?
- does the chosen next evidence target the actual unresolved distinctions?

## Important interpretation

A system designed for disadvantaged observers should not be punished for refusing to decide a question that the public evidence genuinely cannot resolve. The access-curve experiment is specifically designed to distinguish “reasoning failure” from “evidence not available.”
