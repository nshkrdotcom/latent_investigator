# Oracles and Diagnostic Ceilings

Oracles are used to localize failure, not to inflate the headline result.

## Local-judgment oracle

Returns simulator-known answers for judgment classes with exact hidden labels. Examples include true source dependence, true actor access, and compatibility of code-generated event relationships.

For intrinsically semantic surface-text questions, the oracle may be a deterministic renderer label or a hand-authored fixture rather than a claim of metaphysical semantic truth.

## Generation oracle

Injects the simulator's hidden true structured mechanism/world into the candidate set.

If generation-oracle performance is dramatically better than normal generation, candidate discovery is a primary bottleneck.

## Acquisition oracle

Computes the evidence action with maximum pair-separation over simulator-compatible surviving worlds.

## Full diagnostic ceiling

A run may combine generation oracle + local-judgment oracle + acquisition oracle. This measures whether the deterministic core and experiment definitions can recover the intended world when semantic/model uncertainty is removed.

## Interpretation

A poor full-oracle result means the experiment or core logic is wrong. Do not blame the model.
