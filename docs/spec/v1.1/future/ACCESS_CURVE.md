# Future Extension — Epistemic Access Curve

This extension is already supported conceptually by the initial simulator but should be executed only after Gate 1/2.

For each hidden world, rerun under nested access levels and plot:

```text
access level
  -> true-world retention
  -> surviving alternative count
  -> false-world elimination
  -> non-identifiability overclaim
  -> acquisition regret
  -> final report quality
```

This turns the lack of privileged real-world access into an experimental question: how should an investigator reason as a function of what it is permitted to observe?

The system should not become more confident simply because more documents were supplied; confidence/resolution should improve only when the additional evidence is actually discriminating.
