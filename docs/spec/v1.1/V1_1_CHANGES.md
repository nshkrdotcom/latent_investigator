# v1.1 Changes

v1.1 is a small pre-implementation correction release. It does not change the core three-layer architecture.

## Experimental changes

1. Gate 1 now has three co-primary outcomes that cannot be satisfied merely by deterministic provenance bookkeeping:
   - final access-relative material conclusion quality;
   - true-world retention;
   - recovery after planted disconfirmation.
2. Gate 1 adds a compute-matched iterative monolithic baseline beside the ordinary strong monolithic baseline.
3. The simulator now has explicit `resolvable`, `non_identifiable`, and `transition` case classes so blanket hedging and blanket certainty can both fail.
4. Gate 1 uses repeated model runs per simulator seed and reports seed and stochastic-replicate effects separately.
5. Scale is now an axis. A small-case negative result does not refute the long-investigation claim; baseline-only reconnaissance runs before the full structured core is built.
6. The aggregation rule adds a deterministic redundancy-dominance tie-break so a strictly more assumption-heavy world cannot outrank an observationally identical simpler world merely by accreting unsupported detail.
7. A pre-run cost projection is mandatory before the Gate 1 qualification sweep.
8. Evidence-acquisition claims are explicitly simulator-relative because candidate-world prediction uses the controlled environment schema.
9. Literature/novelty diligence begins in parallel with implementation rather than after Gate 1.
10. System One/Jev judgment requests must be bounded slices, not entire investigation dumps; context-limit failures are measured explicitly.

## Still unchanged

- No implementation has been performed.
- System One/Jev probabilities are not treated as global causal likelihoods.
- Search breadth remains a hypothesis with an explicit counter-hypothesis.
- Candidate generation remains an independently measured bottleneck.
- Gate 2 remains conditional on Gate 1.
- External environments and real-case ingestion remain out of scope for the initial implementation.
